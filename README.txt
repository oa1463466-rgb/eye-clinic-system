نظام إدارة عيادة طب وجراحة العيون - النسخة الأولى

المتطلبات:
- Windows 10/11 أو macOS أو Linux
- Python 3.10 أو أحدث
- اتصال إنترنت فقط لتثبيت Flask أول مرة

تشغيل على Windows:
1) ثبّت Python من python.org، وفعل خيار Add Python to PATH أثناء التثبيت.
2) فك ضغط المشروع.
3) افتح Terminal / PowerShell داخل مجلد المشروع.
4) نفّذ:
   py -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   py app.py
5) افتح المتصفح على:
   http://127.0.0.1:5000

بيانات الدخول التجريبية:
اسم المستخدم: admin
